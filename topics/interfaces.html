Peripheral Interfaces

Memory-mapped I/O, GPIO, UART, SPI, I²C, polling, interrupts and DMA.

Present in your uploaded filesSoC design

Core idea

Peripherals expose registers and data paths that software can control through a defined interface.

How to use this page

GPIO handles simple digital signals; UART is asynchronous serial; SPI is clocked serial; I²C is a two-wire addressed bus. The right choice depends on speed, distance, pins and complexity. This page is an organized prototype/reference; the uploaded files remain the detailed source material for the concepts already covered there.
