Core idea

An interconnect provides shared communication paths among processor cores, memory controllers, DMA engines and peripherals.

How to use this page

Common jobs include routing, address decoding, arbitration, bridging and flow control. Protocol details vary by fabric. This page is an organized prototype/reference; the uploaded files remain the detailed source material for the concepts already covered there.
